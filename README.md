# Toys-to-life-emulation
Looking for Help Developing a Universal Toys-to-Life Emulator for PS4

Hello everyone!

I’m interested in developing a PS4 application that emulates multiple toys-to-life portals in one place, allowing players to enjoy these games without needing their original physical portals, figures, or tags.

Games I’d Like to Support

* Disney Infinity: Infinity Base, characters, playsets, and Power Discs.
* Skylanders: Portal of Power, Skylanders, traps, and vehicles.
* LEGO Dimensions: Toy Pad, characters, vehicles, and other tags.

Desired Features

* Emulation of all three portal systems in one application.
* Built-in libraries of characters and accessories.
* Ability to select, switch, and remove virtual characters.
* Support for multiple characters on the portal simultaneously.
* An easy-to-use interface for managing everything.

Ideally, all characters and accessories would be available directly within the application without requiring physical toys.

Looking for Help

I’m hoping to find people with experience in PS4 homebrew development, USB emulation, or toys-to-life hardware.

A few questions:

1. Has anyone started a similar project?
2. Are there existing projects or research that could help?
3. What programming languages and tools should I learn?
4. Would anyone be interested in collaborating or helping teach me how to develop this?

I’m still learning software development, but I’d love to work toward making this project a reality.

The ultimate goal is one universal PS4 Toys-to-Life emulator supporting Disney Infinity, Skylanders, and LEGO Dimensions, with built-in virtual characters and accessories.

Thank you!
